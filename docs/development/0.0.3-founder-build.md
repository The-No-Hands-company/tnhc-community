# Alpha 0.0.3 Founder build implementation record

The separate Founder build is in progress. The product version remains
`0.0.0`; no release has been cut. The member app keeps its existing
`com.tnhc.community.debug` debug ID. The Founder variant installs separately
as `com.tnhc.community.founder.debug`.

## Security boundary

The Founder flavor controls only whether the console can be present. The app
queries the authenticated account's own `platform_roles` row and fails closed
when signed out, denied, or offline. PostgreSQL repeats the Founder check for
every privileged RPC. A unique index permits one Founder assignment, and only
a trusted database operator can provision or recover that role. No Founder
secret, service-role key, signing key, or other elevated credential is embedded
in either APK.

Founder operations implemented in this slice include paginated member and
audit directories; invitation, account-state, administrator/moderator-role,
project, project-membership, topic, topic-membership and post/comment
moderation controls; the maintenance notice and boolean feature flags. Server
mutations and app-setting changes are recorded in an append-only audit log
within the mutation transaction. Audit summaries omit post/comment bodies and
the invitation function omits recipient addresses. General private messages
and host, DNS, backup, certificate, and deployment operations remain outside
the app.

## Build and verification

Build both debug APKs with:

```sh
./gradlew :app:assembleMemberDebug :app:assembleFounderDebug
```

Run unit tests and lint for both variants with:

```sh
./gradlew :app:testMemberDebugUnitTest :app:testFounderDebugUnitTest
./gradlew :app:lintMemberDebug :app:lintFounderDebug
```

Connect a device for the Founder and member UI tests with:

```sh
./gradlew :app:connectedMemberDebugAndroidTest :app:connectedFounderDebugAndroidTest
```

The local database contract was clean-reset and passed **201 pgTAP
assertions**. The invitation Edge Function passed **9 Deno tests** and its
type-check. Both Android flavors compiled, passed unit tests and lint, and both
instrumentation APKs compiled. After moving the flavor tests into Gradle's
recognized `testFounder` and `androidTestFounder` source sets, member unit tests
passed **22/22**, Founder unit tests **30/30**, member emulator instrumentation
passed **18 tests with 1 backend-fixture skip**, and Founder emulator
instrumentation passed **19 tests with 1 backend-fixture skip**. This includes
the Founder console settings readback test and the member/Founder role-gating
Compose tests. The separate two-account live-backend/session-restart scenario
still needs its invitation fixture and remains open.

The minified Founder release R8 task also completed with the provider retained
by the explicit ProGuard rule. R8 emitted Kotlin-metadata parsing warnings
with the configured Kotlin compiler. The check used a throwaway local HTTPS
endpoint and dummy publishable key, and those generated release artifacts were
removed. Review the R8/Kotlin compatibility warning before cutting a release.

The current verified build outputs are under `app/build/outputs/apk/member/debug/`
and `app/build/outputs/apk/founder/debug/`. Configure only the local Supabase URL
and publishable key using the ignored `local.properties` file as documented
in [Android build setup](../BUILDING.md). Follow [the backend provisioning
procedure](../../backend/README.md) out of band to grant Founder to the
intended authenticated account. Test this on a dedicated local database and
emulator before relying on the controls. Public deployment prerequisites and
release signing remain separate gates.
