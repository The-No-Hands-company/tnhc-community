## Device verification

There was no attached Android device. An Android 16 (API 36) x86_64 emulator (Emulator 37.2.12) crashed with a segmentation fault under SwiftShader, with and without Vulkan, before it appeared in ADB. Running it with `-gpu host -feature -Vulkan` worked; that was a problem with the host and emulator, not with the app.

```sh
emulator -avd TNHC_API36 -no-window -no-audio -no-snapshot -no-boot-anim -gpu host -feature -Vulkan
./gradlew :app:connectedDebugAndroidTest
```

Result: **8 of 8 Compose device tests passed** on the emulator. They cover destinations/detail/back, search reset, selected detail/query/category restoration, load retry, empty repository, restored-detail load failure/retry, system Back, and recovery from a missing restored project. The debug APK was installed and launched, and Home and Projects were inspected in light and dark themes. That inspection found Material's default lavender tint on the light navigation bar. The fix was to define `surfaceContainer*` tones in both colour schemes; all unit, lint and device checks were re-run afterwards.
