# Release checklist

- [ ] Milestone acceptance criteria verified; evidence attached to feature IDs.
- [ ] Defects triaged; relevant stage gate passed.
- [ ] Permission, privacy and moderation checks appropriate to audience passed.
- [ ] VERSION and Android versionName match; unused increasing versionCode allocated.
- [ ] App/backend commits, API revision, migration IDs and artifact checksum recorded.
- [ ] CHANGELOG reflects delivered behavior; actual introduced versions populated.
- [ ] Documentation and DevTrack export views agree.
- [ ] Recovery/backup/rollback plan prepared; migrations assessed for rollback safety.
- [ ] Known limitations and distribution audience recorded.
- [ ] Build verified on the selected Android test matrix.
- [ ] Release tag created for the exact commit; artifact distributed through chosen route.
- [ ] Delivery verified; feature statuses changed to released; release date recorded.

Do not mark the checklist complete merely because files or a tag exist.
